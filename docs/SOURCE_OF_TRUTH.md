# Who Took It? / THC Guess Who — Source of Truth

`dtfgenetics/Thc-guess-who` is the canonical code and machine-readable project repository for Who Took It?. It owns structured suspect/item/question data, digital implementation, printable prototype sources tracked in the repo, and validation logic.

Google Drive `04 Games/THC Guess Who` is canonical for approved human-readable game masters, final artwork, print proofs, playtest evidence, and approved release packages.

## Current controlled state

- Printable prototype: v0.8
- Digital prototype: v0.1
- Digital app location: `03_digital-game/`
- Final character art must not be treated as locked until playtesting confirms rules, clue balance, and mode structure.

## Core rule

Every clue/question must resolve to a clear yes or no. Avoid subjective or ambiguous clue logic.

## Release

A release requires structured-data validation, digital build, suspect/item/question alignment, playtest evidence, original/approved art, mode verification, and a separated approved release package in Drive.
